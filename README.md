Web app in `web/` for **apparent solar time**: civil clock time
adjusted for longitude and the Equation of Time, with a live
solar-velocity factor when you move east or west.


It is hosted at [solartime.keenin.com](https://solartime.keenin.com).
Cloudflare Pages deploys `main` with the project root set to `web`.

## What it does


- Apparent solar time to a tenth of a second, and civil vs sun offset
- 24-hour running total of how movement lengthened or shortened the solar day
- Equation of Time (Spencer Fourier), solar noon, sunrise, sunset
- Browser geolocation (`watchPosition`) or manual latitude/longitude
- Location refresh scales with east–west speed; polar motion is dampened


Coordinates, the movement history, and settings stay on the device
(localStorage and IndexedDB). Nothing is sent to a server.


Light and dark follow the system. Text size is in the settings
drawer, which opens from the same side as its button. The first
load caches the app; after that it runs offline. It is an
installable PWA.


## Run, test, and build


Node.js 20 or newer.


```bash
cd web
npm test
npm run build
```


`npm test` runs the unit tests. `npm run build` writes a static
site to `web/dist`. Serve that directory with any static file
server and open it in a browser. The deployed site is
[https://solartime.keenin.com](https://solartime.keenin.com).


Cloudflare Pages uses root directory `web`, build command
`npm run build`, and output directory `dist`.
